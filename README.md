# fajerwoll
## Środowisko testowe
Znajduje się razem z resztą potrzebnych plików w folderze etapV. Aby je uruchomić, należy wykonać plik run.sh.
## Wymagane zależności (Linux)
* iverilog
* python3
* python3-pip

## Wymagane zależności (Python)
* cocotb

## Model firewall'a
W `model` znajdują się skrypty w języku Python modelujące działanie firewall'a i testujące go dla wygenerowanego ruchu.
